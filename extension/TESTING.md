# LINEOA 免審查測試版

## 安裝

1. 使用固定資料夾的一鍵更新器更新；新安裝則解壓縮最新測試版。
2. 在 Chrome 開啟 `chrome://extensions`。
3. 開啟右上角「開發人員模式」。
4. 點選「載入未封裝項目」。
5. 選擇解壓縮後、內含 `manifest.json` 的資料夾。
6. 開啟 `https://manager.line.biz/`。

## 測試流程

1. 在 LINEOA 側欄登入或免費註冊。
2. 至 LINEOA 網站建立至少一筆知識。
3. 回到 LINE OA Manager 並開啟聊天室。
4. 點選左側任一聯絡人，確認 LINEOA 自動更新對方名稱、頭貼與 UID。
5. 再切換另一位聯絡人，確認 LINEOA 自動重新讀取目前可見對話並比對。
6. 確認可見文字預覽正確，再人工複製建議；按鈕只作為手動重新讀取。
7. 切換全版後確認「服務中心／管理工具」可以收合。
8. 進入「串接設定」，確認可填寫及顯示四項 LINE API 參數，Secret／Token 預設遮蔽。
9. 開啟「圖文選單上傳」，確認顯示 30 天試用狀態。
10. 上傳 2500×843 或 2500×1686、1 MB 以下的 JPG／PNG，劃定至少一個區域。
11. 確認圖文選單畫布最大顯示寬度約 720px，不會撐滿大螢幕。
12. 捲動頁面後，確認固定頁首仍可看到「返回串接設定」與「取消並關閉」。
13. 儲存第一份選單，確認右側出現縮圖；新增並儲存第二份選單後，點兩張縮圖可來回切換完整底圖與熱區。
14. 建立點擊區域並選擇「切換選單 (Switch)」，確認會顯示目標 Alias ID 與切換資料 Data，兩者未填時不得部署。
15. 未實際操作正式官方帳號時，不要按「部署至 LINE」；正式測試前確認 Bot token 屬於測試帳號。

## 安全邊界

- 只在 LINE 官方管理頁 `https://manager.line.biz/*` 與聊天室 `https://chat.line.biz/*` 載入。
- 使用者切換聊天室後，自動讀取目前視窗內可見文字並於本機比對。
- 聊天文字於本機比對；對話學習會將已遮蔽常見個資的 QA 草稿保存在擴充功能，人工確認後才上傳題庫。常見個資遮蔽不保證完整，必須複核。
- CRM 開啟自動建檔時，UID、名稱、頭貼與官方帳號會寫入使用者的 LINEOA CRM；不保存聊天全文。
- 不讀取 Cookie、LINE Token 或 LINE Authorization Header。
- CRM 批次掃描會捲動名單、切換聊天室；此時暫停 QA 學習。不填入輸入框、不點擊傳送、不自動發送。
- LINEOA 登入權杖與使用者填寫的 LINE API 參數只保存在 Chrome 擴充功能自己的儲存空間。
- Secret／Token 只會在擴充功能私有設定頁顯示，預設遮蔽，不會放入 LINE 聊天頁 DOM。
- 圖文選單部署由背景程式使用已儲存的 Bot token 直接呼叫 LINE API；menu.html 看不到 token，LINEOA Worker 不保存 token。
- 每次部署前先向 LINEOA Worker 確認 30 天試用或 NT$199／年權限。
- 切換為全版時顯示 ACTION 風格的 LINEOA 管理介面；聊天室監控是其中一個功能頁。

## 更新

### v0.1.23 帳戶編輯

- 管理員用戶名單每列新增「編輯」，擴充功能及網站後台均可修改姓名、公司／品牌、監控 LINE@。
- Email 為唯讀；不更動密碼、角色、狀態、方案、CRM 或知識庫。
- 「取消編輯」不送出資料，返回／關閉仍在固定頁首。儲存後名單立即刷新。
- 資料版本已變更時拒絕覆蓋；請取消編輯、重新整理，再以最新資料編輯。
- 後端逐次驗證管理員，修改與操作紀錄一併寫入；本版不需要資料庫遷移。

### v0.1.22 管理員新增帳戶

- 管理員可由全版「帳戶方案 → 新增／管理用戶帳戶」開啟擴充功能私有管理頁；網站的「使用者管理」也提供相同表單。
- 必填姓名、Email、初始密碼及監控 LINE@（例如 `@abc1234`）；公司／品牌選填。LINE@ 僅保存指定監控對象，並非 LINE 官方帳號授權或所有權驗證。
- 只能建立一般免費用戶，知識庫上限仍為 100 筆。新增帳戶不會切換管理員的登入，也不會寄出密碼通知。
- 重複 Email 回傳錯誤、不覆寫舊帳戶；一般用戶不能呼叫管理員 API。密碼不會顯示於名單或操作紀錄。
- 表單提供取消及固定頁首的返回／關閉；請自行安全交付初始密碼。
- 更新固定資料夾後，先在 Chrome 擴充功能卡片重新載入，再重整 LINE 聊天分頁。尚未合併本分支前，下載 main 的一鍵更新器不會包含此版本。

### v0.1.21 對話預覽修正

- 「目前可見文字」改為「目前對話（客戶／客服）」，依氣泡在畫面的上下順序顯示，最多 40 則。
- 預覽與 QA 學習共用氣泡辨識，不再掃描一般姓名／時間節點。建議回覆只比對客戶訊息。
- 停留在同一聊天室捲動或出現新訊息時，預覽會自動更新。全版模式保留切換前的對話預覽。
- 排除可辨識的引用區塊，並移除引用已讀取提問的重複前綴；無法辨識的引用仍需人工複核。
- 實測時請確認客戶問題與客服回覆都在畫面內；此功能不是歷史聊天全文匯入。

更新固定資料夾後，在 `chrome://extensions` 對 LINEOA 點選「重新載入」，再切回原本的 LINE 聊天分頁。
Chrome 工具列開啟 LINEOA 選單，按「重整目前 LINE 頁面」，或直接在 LINE 分頁按 F5。
只重新載入擴充功能，不會替換已開啟分頁內的舊面板；「重新讀取目前聊天室」也只重讀訊息，不更新程式。

### v0.1.20 重整入口

- 側欄右上角 ↻、全版頁首「重整頁面」、Chrome 工具列 LINEOA 選單都提供頁面重整。
- 選單顯示安裝版本、目前面板版本和背景連線結果；背景連線失敗也能直接重整。
- 重整前提示保存未送出的文字，可以取消。只重整當前 LINE 頁面，不跳回帳號目錄、不清除登入或草稿。
- 版本文字由 manifest 讀取，不再使用過期的手寫版本。

## v0.1.19 對話學習驗收

1. 更新並重新載入擴充功能、重新整理 LINE 聊天頁。側欄顯示「對話學習 · QA 草稿」，預設開啟，可隨時暫停。
2. 客戶的灰色問題氣泡及客服的藍色回覆氣泡須同時完整出現在畫面上；停留約 4 秒，生成待確認草稿。只按本機規則配對，沒有 AI 語意改寫、模型訓練或歷史補抓。
3. 點「檢查／修正 QA」開啟私有頁；檢查問題、答案、分類及個資。短答如「台南」、無回答的問題、不明方向或超長內容不會自動入庫。姓名、地址等仍可能未被遮蔽。
4. 修正為通用問答，儲存修正，重新整理後仍保留。相同原始問答不重複生成，也不覆寫已修改草稿。
5. 未勾選人工確認時禁止加入題庫；確認後才呼叫既有知識庫 API，100 筆上限由伺服器維持。失敗時草稿與修改保留。
6. 返回聊天室按「同步知識庫」，正式 QA 才參與回覆建議。草稿本身不會用來自動回答。
7. 頁首返回／關閉在長頁仍可見；有未儲存修改時提醒。捨棄或移除本機紀錄不會刪除正式知識庫。
8. 草稿按 LINEOA 登入帳號隔離、標示官方帳號，最多 200 筆；保留最近 2,000 個去重指紋。清除擴充功能資料或解除安裝會失去本機草稿。
9. CRM 批次掃描、全版面板或分頁隱藏時暫停擷取；恢復聊天室側欄後繼續。首次辨識需人工實際驗證目前 LINE 頁面樣式。
